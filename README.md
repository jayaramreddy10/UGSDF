## Overview

UGSDF combines 3D Gaussian Splatting and Signed Distance Functions
for dynamic urban scene reconstruction and novel-view synthesis.
Using 2D depth and point-tracking priors, our method jointly learns
geometry and motion without requiring ground-truth 3D motion annotations.
